# flutter_calculator_PhoDucTien
📱 Flutter Calculator App

Simple Calculator following Figma design (StudentLab – Chapter 2)

🇺🇸 English Version
🔥 Features

Basic operations: + - × ÷

Negative numbers (±)

Decimal input

Percentage (%)

CE (Clear End) & C (Clear All)

Operation chaining

Division-by-zero handling

Pixel-perfect UI following Figma specifications:

Primary: #2D3142

Secondary: #4F5D75

Accent: #EF8354

Roboto font

Circular, evenly spaced buttons (16px spacing, 20px padding)

🛠 Tech Stack

Flutter

Dart
